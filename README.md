## Sound Lab. The <ins>NO. 1</ins> Music Streaming Platform.

_Edited by:_ **Joseph Hansel**


### About

This is a website that enables one to access, stream and organise their music files <ins>all</ins> in one place.

>[NOTE]
>This wbsite is still under development.

The users of this website sign up for accounts that enable them to <ins>upload</ins> music, <ins>record</ins> music, and  <ins>store</ins> them. 

The website has _unique graphics_ to augment the streaming experience of the user.

_An audio toolkit_ accompanies the files to enable the user to perform various actions including renaming the files.


### Prospective Improvements

subsequent updates should add the following the following:

-[x] A feature that enables users to share their music with others.
-[x] A feature that enables users to stream from other platforms apart from Spotify.
